% Algoritma/Fungsi: Bilangan Bell B(n) yang merepresentasikan jumlah partisi dari himpunan n elemen berbeda beserta sifat modulonya.
Total number of partitions of n distinct elements.\newline
$B(n)$ = 1, 1, 2, 5, 15, 52, 203, 877, 4140, 21147, ...\newline
For p prime,\newline
$B(p^m+n) \equiv mB(n)+B(n+1)\;(\text{mod}\;p)$
