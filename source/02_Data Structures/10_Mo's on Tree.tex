% Algoritma/Fungsi: Penjelasan formula Mo's Algorithm pada Tree menggunakan Flattening Euler Tour (in/out timer).
% Kompleksitas Waktu: O((N + Q) * sqrt(N) * T_add).
$ST(u) \leq ST(v)$ \newline
$P = LCA(u, v)$ \newline
     If $P = u$, query $[ST(u), ST(v)]$ \newline
             Else query $[EN(u), ST(v)] + [ST(P), ST(P)]$
